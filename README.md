# 주석 찾기 (Sermon Commentary Finder) v1.0.0

옵시디언(Obsidian)에서 성경 66권 전체의 장절별 종합 주석(그랜드 종합주석, 호크마 주석, 매튜 헨리, 스펄전 전권 및 시편강해, 메킨토시 모세오경 등)을 초고속으로 검색하고 한눈에 열람할 수 있는 종합 주석 뷰어 플러그인입니다.

PC 및 **아이패드(iPadOS / 태블릿)** 환경을 완벽하게 지원합니다.

---

## 🌟 주요 기능 및 특징

1. **성경 66권 그랜드종합주석 완벽 수록 (디지털 HWP 3.0 원본 적용)**
   - 스캔 OCR의 오탈자와 노이즈를 100% 제거한 정밀 한글 디지털 원본 텍스트 적용 (약 5,760만 자).
   - 본문 내 수천 개의 비교 도표와 대조표를 `<table class="scf-table">` 구조로 완벽 보존.
   - 표 내부 글씨 크기가 본문 폰트 크기와 동일하게 자동 연동.
   - HWP 원본 상 실제로 존재하는 핵심성구관주(821개), 금언(644개), 예화(514개) 완벽 선별 수록.

2. **풍부한 다중 종합 주석 동시 지원**
   - **호크마 종합주석** (구약/신약 전권)
   - **매튜 헨리 주석** (구약/신약 전권)
   - **스펄전 설교 및 강해** (전권)
   - **스펄전 시편강해** (1~12권 전권)
   - **메킨토시 모세오경** (창세기~신명기)

3. **아이패드(iPadOS) & 모바일 완벽 최적화**
   - 최근 열어본 성경 4권만 메모리에 상주시키는 LRU 스마트 캐시 적용으로 저사양 태블릿에서도 메모리 튕김 없이 0.1초 즉시 로딩.
   - 인터넷 연결이 없는 오프라인 환경에서도 로컬 초고속 구동.

## 📲 설치 및 배포 가이드 (아이패드 & PC 공통)

아이패드 및 PC에서 가장 간편하게 설치하는 2단계 방법입니다.

### 1단계: 플러그인 본체 설치 (BRAT 사용)
1. 옵시디언 설정 $\rightarrow$ **커뮤니티 플러그인** $\rightarrow$ 탐색에서 **BRAT** (`Obsidian42 - BRAT`)을 검색하여 설치하고 활성화합니다.
2. 옵시디언 설정 좌측 메뉴에서 **BRAT** 클릭 $\rightarrow$ **Add Beta plugin** 버튼 클릭.
3. 깃허브 저장소 주소를 입력합니다:
   ```text
   hyod9866/sermon-commentary-finder
   ```
4. 플러그인이 자동으로 다운로드 및 설치됩니다. 이후 **커뮤니티 플러그인** 목록에서 **주석 찾기 (Commentary Finder)**를 켭니다.

---

### 2단계: 주석 데이터 파일 배치 (최초 1회)

성경 66권의 전체 주석 텍스트 데이터(`data/` 폴더)는 깃허브 최신 릴리즈의 에셋에서 1회 다운로드하여 배치합니다.

1. 깃허브 최신 **Release (v1.0.0)** 페이지에서 **`commentary-data.zip`** (약 270MB)을 다운로드합니다.
2. 다운로드받은 압축을 해제하면 `commentary-index.json` 파일과 `data/` 폴더(`b01.json` ~ `b66.json`)가 나옵니다.
3. 압축 해제된 항목들을 아래 옵시디언 플러그인 폴더에 그대로 넣어줍니다:

#### 📍 경로 안내
- **아이패드(iPad)**:
  - 기본 **[파일(Files)]** 앱 실행 $\rightarrow$ `나의 iPad` $\rightarrow$ `Obsidian` $\rightarrow$ `[볼트 폴더]` $\rightarrow$ `.obsidian` $\rightarrow$ `plugins` $\rightarrow$ `sermon-commentary-finder/` 안에 붙여넣기
  > *팁: 아이패드 파일 앱에서 `.obsidian` 숨김 폴더가 보이지 않는 경우, 우측 상단 `···` 버튼 $\rightarrow$ `보기 옵션` $\rightarrow$ `모든 파일 확장자 표시` 또는 외장 파일 관리자(Documents 앱 등)를 사용하시면 쉽게 접근할 수 있습니다.*
- **윈도우 PC(Windows)**:
  - `C:\Users\[사용자명]\Documents\[볼트명]\.obsidian\plugins\sermon-commentary-finder\` 안에 붙여넣기

4. 옵시디언을 다시 시작하거나 플러그인을 껐다 켜면, 성경 66권 전체 주석을 즉시 열람하실 수 있습니다!

---

## 🛠 파일 구성
- `manifest.json`: 플러그인 메타데이터 (아이패드 호환 `isDesktopOnly: false`)
- `main.js`: 플러그인 뷰어 및 검색 렌더링 코어
- `styles.css`: 표(테이블) 및 카드 뷰 스타일시트
- `commentary-index.json`: 39,698개 장절별 주석 색인 인덱스
- `data/`: 성경 66권별 주석 데이터 (`b01.json` ~ `b66.json`, 성경사전 등)
